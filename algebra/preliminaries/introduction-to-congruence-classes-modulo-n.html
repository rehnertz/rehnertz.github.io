模 n 同余类简介

Rehnertz2025/10/10

模 n 同余类简介

整数之间的除法未必能够整除。小学数学中，在引入有理数前我们使用余数来描述无法除尽的部分，而完整研究余数相关性质的理论——数论（number theory）——却在大学数学中才引入，这是因为其具有浓厚的代数学风格．虽然我们的主题是抽象代数，但作为其中最常用的实例，我们非常有必要了解余数相关的概念：模 n 同余类．

整除与最大公因数

定义 1 设 a,b∈Z 且 b=0，若存在 k∈Z 使得 a=bk，则称 b 整除（divide）a，或称 b 为 a 的因数（divisor，factor），记作 b∣a．此时我们也称 a 是 b 的倍数（multiple）．

关于整除有若干非常显然的性质．

命题 1 对任意 a,b,c,s,t∈Z 且 b=0：

  • b∣0；
  • 若 b∣a，则 b∣sa（特别地 b∣−a）；
  • 若 b∣a 且 b∣c，则 b∣(sa+tc)；
  • 设 a=0．若 a∣b 且 b∣c，则 a∣c．

显然对任意 b∈Z∖{0} 都有 b∣0．

定义 2 设 a,b,d∈Z 且 d=0，若 d∣a 且 d∣b，则称 d 是 a 与 b 的一个公因数（common divisor）．a 与 b 的公因数中的最大值称为其最大公因数（greatest common divisor），记作 (a,b) 或 gcd(a,b)．

最大公因数也有若干显然的性质．

命题 2 对任意 a,b∈Z 都有

  • gcd(a,b)=gcd(b,a)；
  • gcd(a,b)=gcd(∣a∣,∣b∣)；
  • gcd(a,0)=∣a∣；
  • gcd(a,1)=1．

与公因数相对，我们有公倍数，不过其应用场景相对较少．

定义 3 设 a,b,m∈Z 且 a,b=0．若 a∣m 且 b∣m，则称 m 是 a 与 b 的一个公倍数（common multiple）．a 与 b 的公倍数中的最小值称为其最小公倍数（least common multiple），记作 [a,b] 或 lcm(a,b)．

定义 4 设 p∈Z+ 且 p=1．若 p 有且只有因数 1 与 p 本身，则称 p 为素数（prime number）．

直观上，素数就是无法进一步有效分解出更小因数的数．

定义 5 设 a,b∈Z，若 (a,b)=1，则称 a 与 b 互素（relatively prime）．

直观上，互素的数之间不存在（1 以外的）公因数．

我们不加证明的给出算术基本定理（正整数唯一分解定理），它是处理整除关系与分析最大公因数性质的有力工具．读者很可能早已熟悉这个结论．

定理 3 对任意大于 1 的正整数 a，存在有限个素数 p1​,p2​,…,pn​ 使得

a=p1​p2​⋯pn​.

若这些素数是有序排列的，即 p1​≤p2​≤⋯≤pn​，则上述素因数分解形式是唯一的．

若将相同的素因数以幂的形式整合在一起，则定理可改写为：唯一存在有限个素数 p1​<p2​<⋯<pn′​ 以及正整数 α1​,α2​,…,αn′​ 使得

a=p1α1​​p2α2​​⋯pn′αn′​​.

使用算术基本定理很容易证明以下性质：

命题 4 对任意正整数 a 和 b 都有

ab=gcd(a,b)⋅lcm(a,b).

带余除法

当 b∣a 时，我们能在整数范围内计算除法 a/b．当 b∤a 时，整数范围内的除法就会留下余数．

定理 5 设 a,b∈Z 且 b=0，则唯一存在一对 q,r∈Z 满足

a=bq+r,0≤r<∣b∣.

我们称 q 为 a 除以 b 的（不完全）商（quotient），称 r 为 a 除以 b（或 a 模 b）的余数（remainder）．

在分析学中要严格地以没有循环论证的方式证明上述定理比较复杂，且依赖于整数的定义．我们不深究自然数与整数的定义，只给出一个能够被广泛接受的证明方法．

证明 我们首先证明 q 与 r 的存在性，然后证明其唯一性．

首先考虑 b>0 的情形．在整个实数轴上可以取以下点列：

…,−3b,−2b,−b,0,b,2b,3b,…,

以它们为端点的区间 [kb,(k+1)b) (k∈Z) 构成 R 的划分．因此，对任意 a∈Z，其必然位于某个区间中．

不妨设 a∈[bq,b(q+1)) (q∈Z)，令 r:=a−bq∈Z，则 r∈[0,b)，因此我们有

a=bq+r,0≤r<b,

证毕．

再考虑 b<0 的情形，此时 −b=∣b∣>0．沿用刚证明的结论，存在 q′,r∈Z 使得

a=∣b∣q′+r,0≤r<∣b∣.

令 q:=−q′ 得到 a=bq+r，证毕．

最后证明 q 与 r 的唯一性．假设同时存在 q,q′,r,r′∈Z 使得

aa​=bq′+r′,=bq′+r′,​0≤r′<∣b∣,0≤r′<∣b∣.​

二式相减得到

b(q−q′)=r′−r.

取绝对值后得到 ∣b∣⋅∣q−q′∣=∣r−r′∣．根据 r 与 r′ 的取值范围，容易证明

−∣b∣<r−r′<∣b∣,

即 ∣r−r′∣<∣b∣，因此 ∣b∣⋅∣q−q′∣<∣b∣，即

∣b∣⋅(∣q−q′∣−1)<0.

这只可能有 ∣q−q′∣−1<0，即 q=q′．进而 r=a−bq=a−bq′=r′，证毕．

按定义，带余除法的除数 b 可以是任意非零整数，但我们主要关注其为正整数的情形．对任意 a,b∈Z 且 b=0，显然 b∣a 当且仅当 a 模 b（的余数）为 0．

考虑任意正整数 n，模 n 所能得到的余数恰有 n 个，即

0,1,2,…,n−1.

全体模 n 得到相同余数 r 的整数均具有形式 kn+r (k∈Z)．

模 n 同余类

定义 6 设 n∈Z+，a,b∈Z，若 a 和 b 模 n 的余数相同，则称它们是同余的（congruent），记作

a≡b(modn).

事实上在数论中我们一般采用同余的另一个等价定义，它更适合用于证明其他性质．

命题 6 设 n∈Z+，a,b∈Z，则 a≡b(modn) 当且仅当 n∣(b−a)．

证明 （⟹）设 a 和 b 模 n 具有相同余数，即存在 q,q′,r∈Z 满足

a=nq+r,b=nq′+r.

于是 b−a=n(q′−q)，故 n∣(b−a)．

（⟸）设 n∣(b−a)，即存在 k∈Z 使得 b−a=kn．设 q,q′,r,r′∈Z 满足

ab​=nq′+r′,=nq′+r′,​0≤r′<n,0≤r′<n,​

则

kn=b−a=n(q′−q)+(r′−r),

因此 ∣r′−r∣=n⋅∣k−q′+q∣．由于 ∣r′−r∣<n，这只可能有 r′=r．

记号 a≡b(modn) 中，≡ 应当理解为类似“=”的等价关系符号，而后面的括号用于补充说明除数．

命题 7 同余关系是等价关系，即对任意 n∈Z+ 和 a,b,c∈Z 都有：

  • 自反性：a≡a(modn)；
  • 对称性：若 a≡b(modn)，则 b≡a(modn)；
  • 传递性：若 a≡b(modn) 且 b≡c(modn)，则 a≡c(modn)．

证明 直接由整除的性质得到．

等价关系可以确定等价类并划分全集．对任意 a∈Z，其在模 n 的同余关系下的等价类记作 [a]n​，称为 a 对应的模 n 同余类（congruence class modulo n）．显然

[a]n​={a+kn∣k∈Z}.

由于不同的余数只有 n 个，全体模 n 同余类也只有 n 个，它们构成的集合记作 Z/nZ，通常称为 n 阶循环群（cyclic group of order n）或 模 n 加法群（additive group modulo n）．这些记号和名称的来源会在学习群论后明晰．显然

Z/nZ={[0]n​,[1]n​,…,[n−1]n​}.

例如，当 n=2 时，

[0]2​[1]2​​={…,−4,−2,0,2,4,…},={…,−3,−1,1,3,5,…}​

分别为偶数和奇数构成的集合，它们不相交但遍历所有整数．

同余类可与整数一样定义加法和乘法运算．设 n 为正整数，对任意整数 a 和 b，定义

[a]n​+[b]n​[a]n​⋅[b]n​​:=[a+b]n​,:=[ab]n​.​

然而我们还需要证明这样的运算是良定义的．例如，设 a≡a′(modn) 且 b≡b′(modb)，即 [a]n​=[a′]n​ 且 [b]n​=[b′]n​，则应当有

[a′+b′]n​=[a′]n​+[b′]n​=[a]n​+[b]n​=[a+b]n​,

只有满足上述条件才能定义出模 n 同余类上的加法运算．

引理 8 设 n∈Z+，a,a′,b,b′∈Z．若 a≡a′(modn) 且 b≡b′(modn)，则

a+bab​≡a′+b′(modn),≡a′b′(modn).​

证明 根据同余的性质，存在 k,ℓ∈Z 使得

a′−a=kn,b′−b=ℓn.

对于加法情形，

(a′+b′)−(a+b)=(a′−a)+(b′−b)=(k+ℓ)n,

因此 n∣[(a′+b′)−(a+b)]，亦即 a+b≡a′+b′(modn)．

对于乘法情形，

a′b′−ab=(a+kn)(b+ℓn)−ab=(aℓ+bk+kℓn)⋅n,

因此 n∣(a′b′−ab)，亦即 ab≡a′b′(modn)．

这实际上也说明同余关系几乎能像等号一样处理加法和乘法运算．

考虑 [5]6​，我们考虑其倍数（也就是通过不断加 [5]6​ 得到其他同余类）能够得到

[5]6​,[15]6​[25]6​​=[3]6​,=[1]6​,​[10]6​[20]6​[30]6​​=[4]6​,=[2]6​,=[0]6​.​

我们发现这正好遍历了 Z/6Z．换言之，只使用 [5]6​ 与加法我们就能得到任意的模 6 剩余类，我们称 [5]6​ 为 Z/6Z 的生成元（generator）．一般地，对于 [a]n​，如果所有的模 n 剩余类都能写成形式 [ka]n​ (k∈Z)，则称 [a]n​ 生成（genrate）Z/nZ．显然 [1]n​ 一定是生成元．在后续学习群论的过程中，我们会得以下结论：

命题 9 设 n∈Z+，[a]n​∈Z/nZ，则 [a]n​ 生成 Z/nZ 当且仅当 gcd(a,n)=1．

同余类的乘法未必可逆，例如

[2]8​⋅[3]8​=[6]8​=[2]8​⋅[7]8​,

这就无法定义 [6]8​ 除以 [2]8​．在实数中，除以一个数等价于乘以其倒数，因此我们在一般情形下都用乘法描述除法．

设 a,b∈Z/nZ，若 ab≡1(modn)，则称 a 和 b 互为（乘法）逆元（inverse），记 b=a−1．

显然若 [a]n​ 是生成元，则它可生成 [1]n​，即存在 [b]n​∈Z/nZ 使得 [ab]n​=[1]n​，从而 [b]n​ 是其逆元．反之，若 [ab]n​=[1]n​，则对任意 [c]n​∈Z/nZ 都有

[c]n​=[ab]n​⋅[c]n​=[a]n​⋅[bc]n​,

因此 [a]n​ 是生成元．于是我们得到了以下结论：

命题 10 设 n∈Z+，[a]n​∈Z/nZ，则 [a]n​ 存在逆元当且仅当 [a]n​ 生成 Z/nZ，当且仅当 gcd(a,n)=1．
