集合系与集合函数（一）

在上一节中我们说明了存在不可测集无法定义测度．根据直觉，当 𝑎 <𝑏 时，ℝ 上的测度 𝜆 对区间 (𝑎,𝑏] 应当是良定义的，即 𝜆((𝑎,𝑏]) =𝑏 −𝑎，所以 𝜆 的定义域应当包含所有 (𝑎,𝑏]．于是，任意可以由这类区间通过交、并、补运算得到的集合也应当可以定义出测度．基于这种思路，我们从全体形如 (𝑎,𝑏] 的区间开始，逐步构造不同的集合系（class of subsetes，表示集合的集合）作为测度的定义域．

区间

对任意 𝑎,𝑏 ∈――ℝ :=[ −∞,∞]，定义区间

(𝑎,𝑏):={𝑥∈ℝ|𝑎<𝑥<𝑏},[𝑎,𝑏):={𝑥∈ℝ|𝑎≤𝑥<𝑏},(𝑎,𝑏]:={𝑥∈ℝ|𝑎<𝑥≤𝑏},[𝑎,𝑏]:={𝑥∈ℝ|𝑎≤𝑥≤𝑏}.

于是当 𝑎 ≥𝑏 时 (𝑎,𝑏) =[𝑎,𝑏) =(𝑎,𝑏] =∅，当 𝑎 >𝑏 时 [𝑎,𝑏] =∅．[𝑎,𝑎] ={𝑎}．

对任意 𝑎 =(𝑎1,…,𝑎𝑛) ∈――ℝ𝑛 和 𝑏 =(𝑏1,…,𝑏𝑛) ∈――ℝ𝑛，定义偏序

𝑎≤𝑏  :⟺∀𝑖∈{1,…,𝑛}:𝑎𝑖≤𝑏𝑖,

定义区间

(𝑎,𝑏):=𝑛∏𝑖=1(𝑎𝑖,𝑏𝑖),[𝑎,𝑏):=𝑛∏𝑖=1[𝑎𝑖,𝑏𝑖),(𝑎,𝑏]:=𝑛∏𝑖=1(𝑎𝑖,𝑏𝑖],[𝑎,𝑏]:=𝑛∏𝑖=1[𝑎𝑖,𝑏𝑖].

此外，为方便书写，对任意 𝑎,𝑏 ∈――ℝ 定义

𝑎∧𝑏:=min{𝑎,𝑏},𝑎∨𝑏:=max{𝑎,𝑏}.

对任意 𝑎 =(𝑎1,…,𝑎𝑛) ∈――ℝ𝑛 和 𝑏 =(𝑏1,…,𝑏𝑛) ∈――ℝ𝑛 定义

𝑎∧𝑏:=(𝑎1∧𝑏1,𝑎2∧𝑏2,…,𝑎𝑛∧𝑏𝑛),𝑎∨𝑏:=(𝑎1∨𝑏1,𝑎2∨𝑏2,…,𝑎𝑛∨𝑏𝑛).

在本节中，我们设全集为 Ω．对任意集合 𝐴，其补集 𝐴𝑐 自然定义为 Ω ∖𝐴．

定义 1 设 S ⊆𝒫(Ω)．我们称 S 是 Ω 上的一个半代数（semi-algebra），若

  • Ω ∈S，
  • 对所有的 𝐴,𝐵 ∈S 都有 𝐴 ∩𝐵 ∈S，
  • 对所有的 𝐴 ∈S 都存在有限个两两不相交的集合 𝐸1,…,𝐸𝑛 ∈S 使得𝐴𝑐=𝑛⨄𝑗=1𝐸𝑗.

半代数的定义启发自 ℝ 上的左开右闭区间．

例 1 令 Ω :=ℝ，

S:={ℝ,∅}∪{(𝑎,𝑏]|𝑎<𝑏, 𝑎,𝑏∈ℝ}∪{(−∞,𝑏]|𝑏∈ℝ}∪{(𝑎,∞)|𝑎∈ℝ},

则 S 是半代数．

读者可以自行验证这一命题，但也可以继续看下一个更一般的例子及其证明．

例 2 令 Ω :=ℝ𝑛，

S:={ℝ𝑛,∅}∪{(𝑎,𝑏]|𝑎<𝑏, 𝑎,𝑏∈ℝ𝑛}∪{(−∞,𝑏]|𝑏∈ℝ𝑛}∪{(𝑎,∞)|𝑎∈ℝ𝑛},

则 S 是半代数．

证明 定义

∞𝑛:=(∞,∞,…,∞)∈――ℝ𝑛,

则 S 中的元素都可以写成

(𝑎,𝑏]∖{∞𝑛}

的形式，其中 𝑎,𝑏 ∈――ℝ𝑛．

任取 𝑎,𝑏,𝑐,𝑑 ∈――ℝ𝑛．对于交运算我们有

((𝑎,𝑏]∖{∞𝑛})∩((𝑐,𝑑]∖{∞𝑛})=((𝑎,𝑏]∩(𝑐,𝑑])∖{∞𝑛}=(𝑎∨𝑐,𝑏∧𝑑]∖{∞𝑛}∈S.

注意：由于我们讨论的是 ℝ 上的集合系，任意集合 𝐴 ⊆ℝ 的补是 𝐴𝑐 :=ℝ∖𝐴 而不是 ――ℝ∖𝐴．对于 ℝ 上的补运算我们有

((𝑎,𝑏]∖{∞𝑛}]𝑐=(𝑎,𝑏]𝑐=𝑛⋃𝑖=1((𝑎1,𝑏1]×⋯×(𝑎𝑖,𝑏𝑖]𝑐×⋯×(𝑎𝑛,𝑏𝑛]),

其中只对第 𝑖 分量上的区间取补．由于

(𝑎𝑖,𝑏𝑖]𝑐=((−∞,𝑎𝑖]∪(𝑏𝑖,∞))∖{∞𝑛},

我们有

(𝑎,𝑏]𝑐=[𝑛⋃𝑖=1((𝑎1,𝑏1]×⋯×(−∞,𝑎𝑖]×⋯×(𝑎𝑛,𝑏𝑛])]∖{∞𝑛}∪[𝑛⋃𝑖=1((𝑎1,𝑏1]×⋯×(𝑏𝑖,∞)×⋯×(𝑎𝑛,𝑏𝑛])]∖{∞𝑛}=𝑛⋃𝑖=1((˜𝑎𝑖,˜𝑏𝑖]∖{∞𝑛})∪𝑛⋃𝑖=1((˜𝑐𝑖,˜𝑑𝑖]∖{∞𝑛}),

其中

˜𝑎𝑖:=(𝑎1,…,𝑎𝑖−1,−∞,𝑎𝑖+1,…,𝑎𝑛),˜𝑏𝑖:=(𝑏1,…,𝑏𝑖−1,𝑎𝑖,𝑏𝑖+1,…,𝑏𝑛),˜𝑐𝑖:=(𝑎1,…,𝑎𝑖−1,𝑏𝑖,𝑎𝑖+1,…,𝑎𝑛),˜𝑑𝑖:=(𝑏1,…,𝑏𝑖−1,∞,𝑏𝑖+1,…,𝑏𝑛)

都是 ――ℝ𝑛 中的点．于是 (𝑎,𝑏]𝑐 是 S 中有限多个元素的并．

定义 2 我们称 A ⊆𝒫(Ω) 是 Ω 上的代数（algebra），若

  • Ω ∈A，
  • 对所有的 𝐴,𝐵 ∈A 都有 𝐴 ∩𝐵 ∈A，
  • 对所有的 𝐴 ∈A 都有 𝐴𝑐 ∈A．

我们显然有以下结论．

命题 1 若 A 是代数，则 A 是半代数．

根据集合运算的 De Morgan 律，我们显然有以下结论．

命题 2 若 A 是代数，则

  • 对所有的 𝐴,𝐵 ∈A 都有 𝐴 ∪𝐵 ∈A．

命题 3 若 A 是代数，则对任意 𝐴,𝐵 ∈A 有 𝐴 ∖𝐵 ∈A．

证明 由 𝐴 ∖𝐵 =𝐴 ∩𝐵𝑐 以及代数的定义得到．

若将交运算（或并运算）的个数从有限推广到可数，则得到 𝜎 代数的定义．

定义 3 我们称 F ⊆𝒫(Ω) 是 Ω 上的 𝝈 代数（𝜎-algebra），若

  • Ω ∈F，
  • 对任意一列集合 𝐴1,𝐴2,⋯ ∈F 都有 ⋂𝑗≥1𝐴𝑗 ∈F，
  • 对所有的 𝐴 ∈F 都有 𝐴𝑐 ∈F．

我们同样有以下两条显然的命题．

命题 4 若 F 是 𝜎 代数，则 F 是代数．

命题 5 若 F 是 𝜎 代数，则

  • 对任意一列集合 𝐴1,𝐴2,⋯ ∈F 都有 ⋃𝑗≥1𝐴𝑗 ∈F．

De Morgan 律

根据 De Morgan 律，代数和 𝜎 代数中有关交运算的定义可以等价地替换为并运算．

代数的记号

代数有时也称为域（field），而 𝜎 代数也可称为 𝝈 域（𝜎-field）．本文中我们用 A 表示代数，用 F 表示 𝜎 代数（𝜎 域）．

由于有限次（或可数次）集合运算都在代数（或 𝜎 代数）中封闭，我们很容易证明任意多个代数（或 𝜎 代数）的交依然是代数（或 𝜎 代数）．

命题 6 设 {A𝛼|𝛼∈𝐼} 是一族代数（或 𝜎 代数），则 ⋂𝛼∈𝐼A𝛼 是代数（或 𝜎 代数）．

证明 按照集合并运算的定义和（𝜎）代数的定义即得．

回忆上一节开头的分析，很显然我们希望测度的定义域是 𝜎 代数．对于 ℝ 上的长度，我们很容易定义区间的长度，而区间并不构成 𝜎 代数，这就要求我们将定义域扩展为包含这些区间的 𝜎 代数．

定义 4 设 C ⊆𝒫(Ω)，则由 C 生成（generate）的代数定义为满足以下性质的集合系 A(C)：

  • A(C) ⊆𝒫(Ω) 是代数；
  • C ⊆A(C)；
  • 对任意代数 B ⊆𝒫(Ω) 都有C⊆B⟹A(C)⊆B.

显然生成代数 A(C) 就是包含 C 的最小代数，且有以下表达．

命题 7 设 C ⊆𝒫(Ω)，则 A(C) 是所有包含 C 的代数的交，即

A(C)=⋂{B|B 是 Ω 上的代数且 C⊆B}

我们可同理将 C 生成的 𝜎 代数定义为包含 C 的最小 𝜎 代数．

定义 5 设 C ⊆𝒫(Ω)，则由 C 生成（generate）的 𝜎 代数定义为满足以下性质的集合系 F(C)：

  • F(C) ⊆𝒫(Ω) 是 𝜎 代数；
  • C ⊆F(C)；
  • 对任意 𝜎 代数 B ⊆𝒫(Ω) 都有C⊆B⟹F(C)⊆B.

命题 8 设 C ⊆𝒫(Ω)，则 F(C) 是所有包含 C 的 𝜎 代数的交，即

F(C)=⋂{B|B 是 Ω 上的 𝜎 代数且 C⊆B}

由于我们已经有如这个例子的半代数，我们希望由它生成一个 𝜎 代数．遗憾的是这样的生成 𝜎 代数的表达非常复杂，但若先放宽要求，则很容易得到生成代数的表达．

引理 9 设 S 是 Ω 上的半代数，则其生成代数由 S 中任意有限多个两两不相交元素的并构成，即对任意 𝐴 ∈A(𝒮) 都存在相应的正整数 𝑛 和两两不相交的 𝐸1,…,𝐸𝑛 ∈S 使得

𝐴=𝑛⨄𝑗=1𝐸𝑗.

证明 我们将 S 中有限多两两不相交元素的并构成的集合记作 B，即

B:={𝑛⨄𝑗=1𝐸𝑗| | | | |𝑛∈ℕ+, 𝐸1,…,𝐸𝑛∈S 两两不相交}.

引理即 A(S) =B．

( ⊇) 任取 𝐴 ∈B，则存在 𝐸1,…,𝐸𝑛 ∈S 使得 𝐴 =⨄𝑛𝑗=1𝐸𝑗．由于每个 𝐸𝑗 ∈S ⊆A(S)，根据代数的定义，𝐴 作为它们的并也在 A(S) 中．

( ⊆) 显然 S ⊆B，我们只要能证明 B 是代数，则根据生成代数的定义可得 A(S) ⊆B．下面我们证明 B 是代数．

  • 显然 Ω ∈S ⊆B．
  • 任取 𝐴,𝐵 ∈B，则存在两两不相交的 𝐸1,…,𝐸𝑛 ∈S 和两两不相交的 𝐹1,…,𝐹𝑚 ∈S 使得𝐴=𝑛⨄𝑗=1𝐸𝑗,𝐵=𝑚⨄𝑘=1𝐹𝑘.于是𝐴∩𝐵=(𝑛⨄𝑗=1𝐸𝑗)∩(𝑚⨄𝑘=1𝐹𝑘)=𝑛⨄𝑗=1𝑚⨄𝑘=1(𝐸𝑗∩𝐹𝑘).根据半代数的定义，𝐸𝑗 ∩𝐸𝑘 ∈S，于是 𝐴 ∩𝐵 是 𝑛 ⋅𝑚 个 S 中两两不相交元素的并，即 𝐴 ∩𝐵 ∈B．
  • 任取 𝐴 ∈B，则存在两两不相交的 𝐸1,…,𝐸𝑛 ∈S 使得𝐴=𝑛⨄𝑗=1𝐸𝑗.根据半代数的定义，对每个 𝐸𝑗 ∈S 都存在有限个两两不相交的 𝐹𝑗,1,…𝐹𝑗,𝑚𝑗 ∈S 使得𝐸𝑐𝑗=𝑚𝑗⨄𝑘=1𝐹𝑗,𝑘.于是𝐴𝑐=(𝑛⨄𝑗=1𝐸𝑗)𝑐=𝑛⋂𝑗=1𝐸𝑐𝑗=𝑛⋂𝑗=1𝑚𝑗⨄𝑘=1𝐹𝑖,𝑗=𝑚1⨄𝑘1=1𝑚2⨄𝑘2=1⋯𝑚𝑛⨄𝑘𝑛=1(𝐹1,𝑘1∩𝐹2,𝑘2∩⋯∩𝐹𝑛,𝑘𝑛)是 S 中有限个两两不相交元素的并，故 𝐴𝑐 ∈B．

定义 6 设 C ⊆𝒫(Ω) 且 ∅ ∈C，𝜇 :C →――ℝ+．我们称集合函数 𝜇 是可加的（additive），若它满足以下性质：

  • 𝜇(∅) =0；
  • 对任意有限多个两两不相交的 𝐸1,…,𝐸𝑛 ∈C，当 ⨄𝑛𝑗=1𝐸𝑗 ∈C 时都有𝜇(𝑛⨄𝑗=1𝐸𝑗)=𝑛∑𝑗=1𝜇(𝐸𝑗).

我们称集合函数 𝜇 是 𝝈 可加的（𝜎-additive），若它满足以下性质：

  • 𝜇(∅) =0；
  • 对任意可数多个两两不相交的 𝐸1,𝐸2,⋯ ∈C，当 ⨄𝑗≥1𝐸𝑗 ∈C 时都有𝜇(⨄𝑗≥1𝐸𝑗)=∑𝑗≥1𝜇(𝐸𝑗).

𝜎 可加的集合函数 𝜇 :C →――ℝ+ 称为 C 上的测度（measure）．

显然 𝜎 可加的集合函数也是可加的．

提示

上述定义中 𝜇(∅) =0 的要求是很自然的．对任意 𝐴 ∈C，根据可加性可得

𝜇(𝐴)=𝜇(𝐴)+𝜇(∅).

若 𝜇(𝐴) <∞，则 𝜇(∅) =0．因此如果 𝜇(∅) ≠0，则 𝜇 =∞，这没有任何研究价值．

可加的集合函数（在对差运算封闭的情况下）是单调的．

命题 10 设 C ⊆𝒫(Ω)，𝜇 :C →――ℝ+ 是可加的．若 𝐸,𝐹 ∈C、𝐸 ⊆𝐹 且 𝐹 ∖𝐸 ∈C，则 𝜇(𝐸) ≤𝜇(𝐹)．若进一步有 𝜇(𝐸) <∞，则 𝜇(𝐹 ∖𝐸) =𝜇(𝐹) −𝜇(𝐸).

证明 由 𝐸 ⊆𝐹 可得

𝐹=𝐸⊎(𝐹∖𝐸),

于是根据 𝜇 的可加性得到

𝜇(𝐹)=𝜇(𝐸)+𝜇(𝐹∖𝐸).

由 𝜇 ≥0 得到 𝜇(𝐹) ≥𝜇(𝐸).

若 𝜇(𝐸) <∞，则可移项得到

𝜇(𝐹)−𝜇(𝐸)=𝜇(𝐹∖𝐸),

即为欲证等式．

对任意集合 𝐴 ⊆Ω，我们定义指示函数（incidator function）1𝐴 :Ω →{0,1} 为

1𝐴(𝑥):={0,𝑥∉𝐴,1,𝑥∈𝐴.

例 3（离散测度） 设 Ω ={𝑥1,𝑥2,…} 是可数集，𝑝1,𝑝2,⋯ ∈ℝ+．定义集合函数

𝜇:𝒫(Ω)→――ℝ+,𝐴↦∑𝑗≥1𝑝𝑗1𝐴(𝑥𝑗),

则 𝜇 是 𝜎 可加的．

证明 显然 𝜇(∅) =0．任取两两不相交的 𝐴1,𝐴2,⋯ ⊆Ω，令 𝐴 :=⨄𝑗≥1𝐴𝑗．对任意 𝑥 ∈Ω，很容易验证 1𝐴(𝑥) =1 当且仅当 ∑𝑘≥11𝐴𝑘(𝑥) =1，也就是

1𝐴=∑𝑘≥11𝐴𝑘,

因此

𝜇(𝐴)=∑𝑗≥1𝑝𝑗1𝐴(𝑥𝑗)=∑𝑗≥1∑𝑘≥1𝑝𝑗1𝐴𝑘(𝑥𝑗)=∑𝑘≥1∑𝑗≥1𝑝𝑗1𝐴𝑘(𝑥𝑗)=∑𝑘≥1𝜇(𝐴𝑘),

即 𝜇 是 𝜎 可加的．

例 4 设 Ω =(0,1)，定义集合系

C:={(𝑎,𝑏]|0≤𝑎<𝑏≤1}

以及集合函数

𝜇:C→――ℝ+,(𝑎,𝑏]↦{∞,𝑎=0,𝑏−𝑎,𝑎>0,

则 𝜇 是可加的，但不是 𝜎 可加的．

证明 先证明 𝜇 不是 𝜎 可加的．考虑分解

(0,12]=⨄𝑗≥1(12+𝑗,11+𝑗].

𝜇 作用在左侧得到 ∞，作用在右侧得到

∑𝑗≥1(11+𝑗−12+𝑗)=12,

两者不相等．

下面证明 𝜇 是可加的．设 (𝑎,𝑏] ∈C 能写成 C 中两个不相交元素 (𝑎1,𝑏1] 和 (𝑎2,𝑏2] 的并．若 𝑎1 和 𝑎2 中有任意一者为 0，则 𝑎 =0，因此

𝜇((𝑎,𝑏])=∞=𝜇((𝑎1,𝑏1])+𝜇((𝑎2,𝑏2]).

若 𝑎1 和 𝑎2 均不为零，不妨设 𝑎1 ≤𝑎2，则必然有 𝑏1 =𝑎2、𝑎1 =𝑎 和 𝑏2 =𝑏，因此

𝜇((𝑎1,𝑏1])+𝜇((𝑎2,𝑏2])=(𝑏1−𝑎1)+(𝑏2−𝑎2)=𝑏2−𝑎1=𝜇((𝑎,𝑏]).

于是 𝜇 是可加的．
