引言：不可测集

在一维空间 R\mathbb{R}R 中，集合有“长度”的概念．对任意满足 a<ba < ba<b 的实数 a,b∈Ra, b ∈ \mathbb{R}a,b∈R，直觉上区间 (a,b)(a, b)(a,b)、(a,b](a, b](a,b]、[a,b)[a, b)[a,b) 和 [a,b][a, b][a,b] 的长度都是 b−ab - ab−a．在二维空间 R2\mathbb{R}^2R2 中，集合有“面积”的概念，其中正方形 [0,1]×[0,1][0, 1] \times [0, 1][0,1]×[0,1] 的面积是 111．与之类似，三维空间 R3\mathbb{R}^3R3 中也有“体积”的概念．

对任意集合 ΩΩΩ，我们可以定义一个函数 μ\muμ，它将某些子集 A⊆ΩA ⊆ ΩA⊆Ω 映射为 [0,∞][0, \infty][0,∞] 中的实数或无穷大，作为对 AAA 的某种性质的测量，并称 μ\muμ 为测度（measure）．长度、面积和体积分别是 R\mathbb{R}R、R2\mathbb{R}^2R2 和 R3\mathbb{R}^3R3 上的测度值．我们将 R\mathbb{R}R 上测量长度的测度记作 λ\lambdaλ，其定义域记作 F\mathcal{F}F．要严格定义 λ\lambdaλ 是非常困难的，这是后续正文的目标之一．不过根据几何直觉，λ\lambdaλ 应当满足以下性质：

  • λ(∅)=0\lambda(\emptyset) = 0λ(∅)=0；
  • 对所有的 a,b∈Ra, b ∈ \mathbb{R}a,b∈R 而言，当 a<ba < ba<b 时都有 λ((a,b])=b−a\lambda\bigl( (a, b] \bigr) = b - aλ((a,b])=b−a；
  • (平移不变性) 对所有 A∈FA ∈ \mathcal{F}A∈F 和 x∈Rx \in \mathbb{R}x∈R 都有 λ(A+x)=λ(A)\lambda(A + x) = \lambda(A)λ(A+x)=λ(A)，其中

    A+x:={ a+x  |  a∈A }. A + x := \Set{a + x | a \in A }. A+x:={a+x∣a∈A}.

  • (可列可加性) 对所有两两不相交的 A1,A2,⋯∈FA_1, A_2, \dots \in \mathcal{F}A1​,A2​,⋯∈F 都有

    λ(⨄i=1∞Ai)=∑i=1∞λ(Ai), \lambda\left( \biguplus_{i = 1}^\infty A_i \right) = \sum_{i = 1}^\infty \lambda(A_i), λ(i=1⨄∞​Ai​)=i=1∑∞​λ(Ai​),

    其中 ⊎\uplus⊎ 与 ∪\cup∪ 一样表示集合的并，但此时强调所有涉及的集合是两两不相交的．这里“两两不相交”指的是对任意不同的指标 i≠ji \neq ji=j 都有 Ai∩Aj=∅A_i \cap A_j = \emptysetAi​∩Aj​=∅．

可列可加性是平面几何中面积割补法的基础．

根据几何直觉，我们有理由相信这样的 λ\lambdaλ 是存在的，否则平面几何就会有问题．于是我们自然会想：λ\lambdaλ 的定义域是否包括所有 R\mathbb{R}R 的子集？也就是是否所有 R\mathbb{R}R 的子集都可以测量出长度？本节我们证明（在接受选择公理的前提下）这是不可能的，因此存在不可测集．

对任意集合 Ω\OmegaΩ，我们用 P(Ω)\mathscr{P}(\Omega)P(Ω) 表示其幂集——所有 Ω\OmegaΩ 的子集构成的集合．假设存在函数 λ:P(R)→[0,∞]\lambda : \mathscr{P}(\mathbb{R}) \to [0, \infty]λ:P(R)→[0,∞] 满足前文所列出的四条性质，我们来导出矛盾．我们首先给出 λ\lambdaλ 的单调性．

断言 若 A⊆B⊆RA \subseteq B \subseteq \mathbb{R}A⊆B⊆R，则 λ(A)≤λ(B)\lambda(A) \leq \lambda(B)λ(A)≤λ(B)．

证明 由 A⊆BA \subseteq BA⊆B 可得

B=A⊎(B∖A), B = A \uplus (B \setminus A), B=A⊎(B∖A),

若令 E1=AE_1 = AE1​=A，E2=B∖AE_2 = B \setminus AE2​=B∖A，Ei=∅ (i≥3)E_i = \emptyset\ (i \geq 3)Ei​=∅ (i≥3)，则

λ(B)=λ(⨄i=1∞Ei)=∑i=1∞λ(Ei)=λ(A)+λ(B∖A).\begin{aligned} \lambda(B) &= \lambda\left( \biguplus_{i = 1}^\infty E_i \right) = \sum_{i = 1}^\infty \lambda(E_i) \\ &= \lambda(A) + \lambda(B \setminus A). \end{aligned} λ(B)​=λ(i=1⨄∞​Ei​)=i=1∑∞​λ(Ei​)=λ(A)+λ(B∖A).​

由于 λ≥0\lambda \geq 0λ≥0，λ(B)≥λ(A)\lambda(B) \geq \lambda(A)λ(B)≥λ(A)．

为了构造不可测集，我们定义 R\mathbb{R}R 上的关系：

x∼y  : ⁣ ⁣  ⟺  x−y∈Q, x \sim y \ \ :\!\!\iff x - y \in \mathbb{Q}, x∼y  :⟺x−y∈Q,

其中 x,y∈Rx, y \in \mathbb{R}x,y∈R．任意实数 xxx 的等价类记作

[x]:={ y∈R  |  x∼y }. [x] := \Set{y \in \mathbb{R} | x \sim y}. [x]:={y∈R∣x∼y}.

断言 对任意 x∈Rx \in \mathbb{R}x∈R 而言，[x][x][x] 都与区间 (0,1)(0, 1)(0,1) 相交．

证明 

  • 若 xxx 是整数，则 0∈[x]0 \in [x]0∈[x]，故 0.1∈[x]0.1 \in [x]0.1∈[x]．
  • 若 xxx 不是整数，则其小数部分 x−⌊x⌋∈(0,1)x - \lfloor x \rfloor \in (0, 1)x−⌊x⌋∈(0,1)．

我们从每个等价类中取出一个 (0,1)(0, 1)(0,1) 中的元素构成集合 Ω⊆(0,1)\Omega \subseteq (0, 1)Ω⊆(0,1)．这意味着 Ω\OmegaΩ 中不同的元素来自于不同的等价类．

断言 若 p,q∈Qp, q \in \mathbb{Q}p,q∈Q，则要么 Ω+p=Ω+q\Omega + p = \Omega + qΩ+p=Ω+q，要么 Ω+p\Omega + pΩ+p 与 Ω+q\Omega + qΩ+q 不相交．

证明 若 Ω+p\Omega + pΩ+p 和 Ω+q\Omega + qΩ+q 相交，则可从中取出一个元素 xxx．换言之，存在 x∈Ωx \in \Omegax∈Ω 以及相应的 α,β∈Ω\alpha, \beta \in \Omegaα,β∈Ω 使得

x=α+p=β+q. x = \alpha + p = \beta + q. x=α+p=β+q.

于是 x∼αx \sim \alphax∼α 且 x∼βx \sim \betax∼β，从而 α∼β\alpha \sim \betaα∼β．由于 Ω\OmegaΩ 中不同的元素来自不同的等价类，这只可能有 α=β\alpha = \betaα=β，从而 p=qp = qp=q．

定义

Φ:=⨄q∈Q−1<q<1(Ω+q), \Phi := \biguplus_{\mathclap{\substack{q \in \mathbb{Q} \\ -1 < q < 1}}} (\Omega + q), Φ:=q∈Q−1<q<1​⨄​(Ω+q),

λ(Φ)≤λ((−1,2])=3. \lambda(\Phi) \leq \lambda\bigl( (-1, 2] \bigr) = 3. λ(Φ)≤λ((−1,2])=3.

根据 λ\lambdaλ 的可列可加性与平移不变性可得

λ(Φ)=∑q∈Q−1<q<1λ(Ω+p)=∑q∈Q−1<q<1λ(Ω)≤3.\begin{aligned} \lambda(\Phi) &= \sum_{\mathclap{\substack{q \in \mathbb{Q} \\[0.5ex] -1 < q < 1}}} \lambda(\Omega + p) \\ &= \sum_{\mathclap{\substack{q \in \mathbb{Q} \\[0.5ex] -1 < q < 1}}} \lambda(\Omega) \leq 3. \end{aligned} λ(Φ)​=q∈Q−1<q<1​∑​λ(Ω+p)=q∈Q−1<q<1​∑​λ(Ω)≤3.​

常数列构成的级数收敛，这意味着 λ(Ω)=0\lambda(\Omega) = 0λ(Ω)=0，从而 λ(Φ)=0\lambda(\Phi) = 0λ(Φ)=0．然而下面的断言表明这是不可能的．

断言 (0,1)⊆Φ(0, 1) \subseteq \Phi(0,1)⊆Φ

证明 对任意 x∈(0,1)x \in (0, 1)x∈(0,1)，唯一存在 α∈[x]∩Ω⊆(0,1)\alpha \in [x] \cap \Omega \subseteq (0, 1)α∈[x]∩Ω⊆(0,1)．定义
