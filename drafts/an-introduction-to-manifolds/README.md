# 流形导论

我们在高等数学中学习过曲线与曲面积分．尽管我们从未严格对“维度”这个概念下定义，我们也知道曲线是一维的，曲面是二维的，只不过它们都可以“嵌入”在三维空间 $\mathbb{R}^3$ 中．曲线与曲面的高维扩展是**流形**．简单地说，流形是局部能够近似为欧几里得空间 $\mathbb{R}^n$ 的几何体，例如地球可以近似视作光滑球面，而球面上的局部区域可以近似视作二维平面（就如同我们看地面是平的一样）．此时地球表面是一个二维流形．

本文是光滑流形理论的<del>抄书</del>学习笔记，记录流形理论的入门知识，主要参考文献为：

- Tu L.W. An Introduction to Manifolds[M]. New York, NY: Springer New York, 2011.

流形理论需要基础的点集拓扑知识．上述教材的附录对此有最基本的介绍，也可参考这一篇笔记：[点集拓扑速成](/posts/crash-course-in-point-set-topology)．
