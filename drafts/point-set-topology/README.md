# 点集拓扑

本文是以下书籍的书摘．

- CONWAY J B. *A Course in Point Set Topology* [M]. 1st ed. Cham: Springer Nature, 2013.

点集拓扑是现代数学分析的基础语言工具，许多大一在《高等数学》或《数学分析》中学习的概念（如数列极限、函数的连续性）都可以用点集拓扑的语言扩展到更一般的情景中．与多数教材不同，这本书首先介绍与我们熟悉的实数空间类似的度量空间，然后再将度量空间扩展到一般的拓扑空间，这会更有助于一般读者接受并学习点集拓扑．这本书很薄，通篇也就 150 页左右，但能够了解点集拓扑作为语言工具的所有必要知识．

::: info 关于翻译风格
英文与中文的语序存在很大不同，在定义中几乎都是先给出名称后给出性质，例如：

- 有序对 $(X, d)$ 称为度量空间，若 $X$ 是集合，$d$ 是函数，满足……．

按照中文的习惯，一般需要颠倒顺序，例如：

- 设 $X$ 是集合，$d$ 是函数，若满足……，则称 $(X, d)$ 是度量空间．

然而数学是非常讲究逻辑的，行文方式也会影响读者的理解方式．经过权衡，我认为译文依然按照英文语序最适合数学领域．
:::
